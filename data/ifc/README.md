# Design model (IFC)

`IFC Schependomlaan.ifc` is the complete design model of the Schependomlaan
building, the only raw file the pipeline reads (P1 parse, materials, P2
stages, P3 simulation, P4 matching and visibility).

It is a copy of `Design model IFC/IFC Schependomlaan.ifc` from the
Schependomlaan dataset, https://github.com/jakob-beetz/DataSetSchependomlaan,
(C) original owners, licensed under Creative Commons Attribution 4.0
International (http://creativecommons.org/licenses/by/4.0/). Unchanged.

The rest of that dataset (5.5 GB: drone images, point clouds, planning) is not
needed here; clone it into `data/raw/schependomlaan/` if you want it
(docs/SPEC.md section 4.1).
